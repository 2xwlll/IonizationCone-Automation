# Current NGC 1068 slit comparison

Latest figures and scientific interpretation: [slit comparison README](../../results/cloudy/ngc1068_slit_comparison_v2/README.md).

The 2023-08-24 ESO spectrum is now compared with a model extraction reproducing the verified 0.90″ × 3.99″ archive aperture, with a separate ground-based seeing operator. Its bright compact continuum peak lies outside the selected spatial rows. Registration along the slit uses that continuum peak; cross-slit registration remains uncertain and is represented by explicit alternatives. The model remains 2D and its physical parameters are unchanged.

The atmospheric correction remains `results/cloudy/ngc1068_telluric_dry_v1`; model extractions are `results/cloudy/ngc1068_matched_slit_v3`. No fitted line strengths or synthetic gap filling are used. See the README before interpreting discrepancies as physical constraints.
